# Prose lens: PRD Addendum (`addendum.md`)

**Purpose read:** this document exists to help the architect and engineers build the engine, the Seed Agents, and third-party Agents against exact contracts (Type schemas, x402 wire, Settlement math), and to hand the pitch owner the demo-script corrections those contracts force. Same read as the structure lens; nothing here changes it.

**Reader type:** humans. **Style guide:** Microsoft Writing Style Guide (configured default). **Word metrics:** reused from the structure lens run of `word_metrics.py` (1,990 words total); the prose fixes below add about 30 words.

**Voice to preserve:** spec register. Short declarative sentences, label-led bullets ("Method: …", "Timeouts: …"), and fragments where a full sentence adds nothing. British spelling (behaviours, authorisation, serialises, decentralises) matches the PRD. Lowercase "chat id", "chain id", "tx hash", "the platform", and lowercase "facilitator" for the software as opposed to the Facilitator role all mirror the PRD glossary and are left alone. "Settlement receipt" in §3 is the PRD's own phrase for the x402 receipt and is left alone. Code formatting for Type names, field names, and HTTP headers. JSON blocks and tables were treated as code and not restyled. Structure-lens dispositions were respected: every row below sits on text that survived that pass.

5 further minor fixes; ask to expand: (a) the intro mixes "Sections 1 to 4", "§7", and "Section 8" in one paragraph, pick one form; (b) §3 "must equal the Listing exactly" reads better as "must match the Listing exactly"; (c) §5 Platform Exchange Account "go through it; … is its balance" is clearer as "that account" twice, since the preceding clause names a key, not the account; (d) §8 Cost figures "All five Types are paid Listings" conflates two glossary terms, "All five Seed Agents are paid Listings" keeps the meaning; (e) enum values are code-formatted in §1 (`LONG`, `HOLD`) and plain in §4 and §8 prose (LONG, BUY), align if desired, tables excluded.
